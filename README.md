# 🌶️ 重慶 7 天 6 夜智慧旅遊行程規劃中心 ‧ Travel Planner

Notion 風格的智慧旅遊行程規劃中心，具備 Firebase Firestore 雲端跨裝置即時雙向同步功能。

## 🌟 功能亮點
- **Notion 雙欄美學佈局**：快速導覽、雙住宿切換、交通航班資訊、即時匯率概算。
- **7 天魔幻山城時間軸**：精準收錄武隆天生三橋、長江索道、下浩里、三峽博物館、來福士烤匠、無人機表演、磁器口等深度行程。
- **☁️ 雲端跨裝置即時同步**：串接 Google Firebase Firestore，手機與電腦雙向即時連動，多人共同編輯免重新整理。
- **📖 隨身旅遊小手冊**：一鍵預覽並列印 A4 PDF 專屬旅遊隨身手冊。
- **🖼️ Notion 封面選擇器**：支援精選旅遊主題圖庫、本地電腦圖片上傳與網址連結。

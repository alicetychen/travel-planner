📖 第一次使用？如何 1 分鐘免費取得 Firebase Config？ (點擊展開教學)
步驟 1：前往 Firebase Console，登入 Google 帳號並點「新增專案」（可取名例如 my-trip，關閉 Google Analytics 即可）。
步驟 2：進入專案首頁，點左側「Firestore Database」➔ 點「建立資料庫」➔ 安全規則選擇「以測試模式啟動 (Test Mode)」完成建立。
步驟 3：點左上角「專案總覽」旁的齒輪 ⚙️ ➔「專案設定」，在下方「您的應用程式」點擊網頁圖標 </>。
步驟 4：複製畫面中的 const firebaseConfig = { ... };，完整貼回上方輸入框，按下「儲存設定並開始即時同步」即可！
